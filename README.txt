開始使用
1. 用 Chrome / Edge 開啟 index.html；整個資料夾放在一起，無須連線。
2. 左右鍵／空白鍵翻頁，F 全螢幕，O 概覽，S 講者視窗，N 本頁講稿。
3. 「資料來源」跳到第16頁；「故事線」提供每頁一句的講解方向。
4. 點頁底來源查看頁碼、證據限制及原文網址。公開原文需要網絡。
5. 若瀏覽器阻擋講者視窗，允許本次彈窗後再按 S。

編輯與重建
編輯data/content.json後執行 python3 scripts/build.py（建議Python 3.12或以上）。
style.css：原版面；revision.css：修訂頁版面；heading-font.css：宋體標題。
motion.css：頁內動畫；evidence-intro.css/.js：新首頁及文件過渡；notes-controls.js：講稿字級。
data/focus_points.json：第2–15頁的重點位置清單；data/content.json內data-focus標記對應實際區塊。
data/evidence_intros.json：各頁啟用狀態、文件卡標題、上下文及重點摘述、來源ID與頁碼；首頁及兩頁來源附頁設定為停用。
生成器只需Python標準函式庫。初次製作的seed_content.py與prepare_research.py不放入分享包。
qa/保留實際驗證結果；PDF須另由瀏覽器列印／匯出，build.py不會重建PDF。
